# inPeDF

Leitor de PDF leve para Linux.

Simples, rápido e focado apenas no que importa.

## Recursos

- Abrir arquivos PDF
- Navegar entre páginas
- Interface GTK 4 / Libadwaita
- Integração com Ubuntu/Linux
- Suporte a internacionalização

## Objetivo

Manter o inPeDF simples, leve e fácil de usar.
